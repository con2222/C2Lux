# C2Lux

**C2Lux** — это легковесная, кроссплатформенная 3D-песочница и интерактивная лаборатория шейдеров, написанная с нуля на **C++17** и **WebGPU (Google Dawn)**. 

Проект задуман как образовательная площадка для экспериментов с алгоритмами освещения в реальном времени, архитектурой пользовательских шейдеров и современными графическими технологиями.

> **Статус проекта: Ранняя разработка (v0.0.1-alpha)** > Проект находится в стадии активной разработки. Архитектура быстро развивается, и регулярно добавляются новые функции.

---

## Текущие возможности

- **Загрузка 3D-моделей:** Парсинг и загрузка сеток `.obj` (Wavefront) в реальном времени с поддержкой вершинных атрибутов (позиции, нормали, запеченные цвета и UV-координаты).
- **Пользовательский шейдинг Блинна-Фонга:** Чистая WGSL-реализация классической модели отражения Блинна-Фонга, объединяющая фоновое (ambient), рассеянное (diffuse) и зеркальное (specular) освещение.
- **Настройка параметров на лету:** Полностью интерактивная панель управления на базе **Dear ImGui** для изменения направления света, фактора фонового затенения, интенсивности света, глянца материала и силы блика в реальном времени.

## Планы и развитие (Roadmap)

Конечная цель **C2Lux** — стать гибкой средой для тестирования графики и экспериментов с рендерингом. Предстоящие обновления включают:

### 1. Расширение моделей освещения
- Переход от модели Блинна-Фонга к **физически корректному рендерингу (PBR)** с использованием микрофасетной модели Cook-Torrance.
- Добавление поддержки множества источников света (точечные, направленные) с физическим затуханием.

### 2. Переключение шейдеров и стандартизация
- **Горячая перезагрузка шейдеров:** Возможность динамически переключаться между различными графическими пайплайнами и файлами WGSL во время работы программы для наглядного сравнения.
- **Стандарт шаблонов шейдеров C2Lux:** Создание строгой спецификации для пользовательских шейдеров. Следуя шаблону, который привязан к внутренним структурам движка, пользователи смогут писать собственные шейдеры и загружать их прямо в приложение.

### 3. Тени и симуляция окружения
- **Карты теней (Shadow Mapping):** Реализация рендера глубины для создания реалистичных динамических теней.
- **Спавн препятствий:** Добавление возможности размещать в сцене простые процедурные формы (стены, блоки, примитивы), которые будут отбрасывать тени.

### 4. Текстурирование и материалы
- Переход от вершинных цветов к полноценному **текстурированию** (Albedo, Normal, Roughness/Metallic карты), загружаемому из файлов `.mtl`.

### 5. Собственная математическая библиотека
- **Отказ от GLM:** Разработка собственной легкой 3D математической библиотеки с нуля для замены зависимости от GLM.

### 6. Модернизация UI/UX
- **Кастомный стиль ImGui:** Замена стандартной темной темы на современную цветовую палитру, настройка отступов и плавное скругление окон.
- **Организация макета:** Группировка параметров в сворачиваемые списки и вкладки для поддержания чистоты рабочего пространства по мере роста функционала.

### 7. Расширенная поддержка ассетов
- **Новые 3D-форматы:** Добавление поддержки современных форматов моделей, таких как `.gltf` и `.fbx`, в дополнение к `.obj`.
- **Текстуры из изображений:** Реализация загрузки популярных форматов изображений (JPEG, PNG) для рендеринга сложных материалов.

## Стек технологий

- **Ядро:** C++17
- **Графический API:** WebGPU через фреймворк Google Dawn
- **Окна и ввод:** GLFW
- **GUI:** Dear ImGui
- **Математика:** GLM (OpenGL Mathematics)
- **Загрузка ассетов:** tinyobjloader & stb_image

## Сборка проекта

### Требования
- Компилятор с поддержкой C++17
- CMake 3.20 или новее
- Совместимая видеокарта с поддержкой Vulkan, DirectX 12 или Metal

### Компиляция
```bash
git clone https://github.com/con2222/C2Lux.git
cd C2Lux

# На Linux укажите USE_WAYLAND=ON или USE_X11=ON
cmake -S . -B build
cmake --build build
```
